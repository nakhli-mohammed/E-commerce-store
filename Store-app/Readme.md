# Gym Store Website

> A static multi-page website for a fictional gym clothing and accessories store, built using HTML and CSS in 2023.

## 📄 Description

This project is a complete frontend-only website for a fictional online store that sells gym clothes and fitness accessories.  
It includes essential e-commerce pages such as a homepage, shop page with product listings, user account page, contact form, and a newsletter subscription form.

All pages are built using only HTML and CSS—no JavaScript or backend—making this a static prototype meant for design practice and learning structure.

## 💡 Features

- Multi-page structure:
  - **Home** – Introduction and highlights of the store
  - **Shop** – Product listings for gym clothes and accessories
  - **Account** – Basic form for login or account details
  - **Contact Us** – Form for customer messages or inquiries
  - **Subscribe** – Newsletter sign-up form
- Navigation bar and footer
- Styled product cards with images and descriptions
- Multiple HTML forms (Account, Contact, Subscribe)
- CSS layout and design
